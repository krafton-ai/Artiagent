🎯 1. Artifact 정의

Image Artifact란:

T2I 생성 모델에 의해 생성된 이미지 내에서 의도되지 않았거나, 불가능하거나, 시각적으로 손상된 영역을 의미합니다. 이러한 artifact는 종종 이미지의 자연스러운 의도나 시각적 일관성을 깨뜨리며, 손가락이 추가된 사람, 바퀴가 모자란 자동차, 신체 일부가 없는 동물 등이 있으며, 이미지 품질이나 현실성을 크게 저하시킬 수 있습니다.

✅ 본 연구의 초점: 구조적(Structural) Artifact

  • Distortion: 불가능한 기하학적 구조를 가진 물체 혹은 흐리고 깨진 구조의 물체
  • Removal: 불완전한 물체나 신체 부위
  • Addition: 중복되거나 추가된 요소
  • Fusion: 부자연스럽게 합쳐진 것들

❌ Artifact로 간주하지 않는 것

  • 텍스트 왜곡: 흐려지거나 잘못된 텍스트
  • 스타일 오류: 이미지 스타일의 비현실성 (애니메이션이나 그림과 같은 이미지의 스타일)
  • 물리적 불가능성: 비현실적이지만 구조적인 이상이 없는 장면
  • 프롬프트 일치 여부: 설명과 일치하지 않는 이미지 / 프롬프트가 artifact 생성을 의도하는 경우

🏷️ 2. Artifact 종류

Addition

정의: 중복되거나 반복되어 이미지의 현실성을 해치는 구성 요소.

예시:

  • 6개 이상의 손가락을 가진 사람
  • 여분의 바퀴를 가진 자동차
  • 여러 개의 머리를 가진 동물
  • 중복된 신체 부위
Removal

정의: 있어야 할 구성 요소가 누락된 상태.

예시:

  • 손가락이 없는 사람
  • 바퀴가 없는 자동차
  • 필요한 구성 요소 누락
  • 불완전한 얼굴 특징
Distortion

정의: 알아볼 수 없이 뒤틀리거나 깨어져 비정상적인 디테일을 가진 물체.

예시:

  • 휘어진 얼굴이나 사지
  • 비틀린 건축 요소
  • 뒤섞인 물체 부분
  • 기하학적 이상
Fusion

정의: 경계가 불명확하게 함께 융합된 물체.

예시:

  • 두 사람이 하나로 융합
  • 함께 블렌딩된 물체
  • 모호한 혼합 부분
  • 구별할 수 없는 요소
🤷 확실하지 않음

정의: 잘못된 부분을 볼 수 있지만 어떤 특정 범주에 속하는지 결정할 수 없을 때.

사용할 때:

  • 여러 범주 간에 애매한 아티팩트
  • 결함이 보이지만 성격이 불분명함
  • 특성이 겹치는 복잡한 아티팩트
  • 관찰한 내용을 설명하는 데 중점
참고: "확실하지 않음"을 사용할 때는 카테고리화를 시도하지 말고 무엇이 잘못되어 보이는지 자세한 설명을 제공하세요.

✅ 3. Classification 가이드라인

Classify 과정:

  1. 전체 이미지를 주의깊게 살펴보세요.
  2. 구조적 artifact를 찾아보세요.
  3. 각 artifact 종류를 고려하세요
  4. 최종 결정:
    • Has Artifacts - 명확한 구조적 결함이 있을 때
    • No Artifacts - 구조적 문제가 발견되지 않았을 때
    • Unsure - 별도 확인이 필요한 불확실할 때

주의사항:

  • 충분히 시간을 들이세요 - 속도보다 정확성
  • 구조에 집중하세요 - 스타일이나 현실성과 관계 없음
  • 모든 부분을 확인하세요 - 한 눈에 보이지 않을 때가 많음
  • 의심스러울 때는 - "Unsure" 옵션 사용
  • 예시를 참조하세요 - 제공된 사례와 비교
기억하세요: 처음에는 괜찮아 보이는 이미지도 artifact을 포함할 수 있습니다. 다음에 특히 주의하세요:
  • 손, 손가락, 신체 부위
  • 얼굴과 얼굴 특징
  • 건축 요소
  • 물체 경계

🎨 4. Annotation 가이드라인

Bbox 그리기:

  • 클릭하고 드래그하여 박스를 그리세요
  • Artifact 주위로 박스를 만드세요
  • 각각의 요소 당 하나의 박스
  • 전체 artifact을 박스에 포함시키세요

카테고리 선택:

  • 각 영역의 주요 artifact 종류를 선택하세요
  • 정의와 일관되게 하세요
  • 모든 박스마다 카테고리가 있어야 합니다

캡션 작성:

  • 구체적으로 작성하세요
  • 무엇이 잘못되었는지 설명하세요
  • 간결하게 정보를 제공하세요
  • 모든 박스마다 캡션이 있어야 합니다
